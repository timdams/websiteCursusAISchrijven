Je werkt in de Claude-app op je computer, aangemeld met je Claude-abonnement.

1. Maak in Claude een nieuw **project**. Wijs bij het aanmaken naar je lege map op je harde schijf:
   daar komt je cursus.
2. Open je project, en zet de modus van **Chat** op **Cowork**. In Cowork werkt Claude zelf in je map.
3. Stel als eerste vraag:

   ```{.kopieer}
   Ik wil een eenvoudige cursus in Quarto, met een website. Zet alles klaar. Voorlopig wil ik alles op mijn eigen computer testen: online zetten is voor later. Ik ken Quarto nog niet, dus keep it simple.

   Voorzie een duidelijke plek voor mijn cursustekst, met een duidelijke mappenstructuur. Voorzie ook een map voor mijn achtergrond, en zeg me wat daarin moet.

   Zet in de hoofdmap een document HELP.md waarin je uitlegt hoe ik in de toekomst met deze cursus werk, vanuit mijn Claude-project in Cowork. Leg zeker uit hoe ik teksten schrijf en hoe ik de website test.
   ```

4. Lees wat Claude voorstelt, en laat het werken. Vraagt het iets te installeren, lees dan eerst wat
   het is.
5. Open *HELP.md* in je map, en volg de uitleg om je website te bekijken.
